# Course maps

Upload a course map image into this folder with these names. The Races page shows it automatically; until then it says "Course map coming soon".

- `race-1-map.jpg` — Race #1 (01/13/2027)
- `race-2-map.jpg` — Race #2 (01/27/2027)
- `race-3-map.jpg` — Race #3 (02/10/2027)
- `race-4-map.jpg` — Race #4 (02/24/2027)

`.png` works too (e.g. `race-1-map.png`). Laps, lap length, parking and course notes are text in each race page (`race-1.html` … `race-4.html`) — edit them on GitHub with the pencil icon.
